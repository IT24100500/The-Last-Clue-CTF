ACCOUNT / PRIVILEGE NOTES
-------------------------
- The intended Levin-to-Bella transition is horizontal movement between
  user accounts, not vertical privilege escalation.
- The final stage may use a deliberately configured, narrowly scoped
  sudo privilege for the CTF account.
- Use CTF-only credentials, keys, flags, and evidence.
- Stage 3 is a standalone Python challenge; it does not require Flask or
  another web server.

SECURITY BOUNDARY
-----------------
- Use a VirtualBox Host-only network for the isolated lab.
- Avoid unrestricted bridged networking during the demonstration.
- The intended exposed Ubuntu services are TCP/22 (SSH) and TCP/80 (HTTP).
- Verify actual listening ports and reachability from Kali; do not assume
  this architecture is already implemented or tested.
